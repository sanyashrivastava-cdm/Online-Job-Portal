# JobHub - Online Job Portal

## Project Overview
JobHub is an online job portal that connects jobseekers
with recruiters.

## Technologies Used
- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
- Maven

## Features
- User Registration
- User Login
- Jobseeker Dashboard
- Recruiter Dashboard
- Search Jobs
- View Available Jobs
- Post a Job
- Manage Applications

## Database
MySQL is used for database management.

## How to Run the Project

1. Install Java and MySQL.
2. Open the project folder in VS Code.
3. Start MySQL Server.
4. Open the terminal in the project directory.
5. Run the following command:

   .\mvnw.cmd spring-boot:run

6. Wait for the Spring Boot application to start.

## Project Structure

- src/main/java: Java source code
- src/main/resources: Application configuration
- pom.xml: Project dependencies
- README.md: Project documentation
